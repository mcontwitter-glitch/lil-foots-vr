# Bigfoot Country VR — Lil' Foots WebXR world (BIGfoot.biz)

A misty pine-forest clearing at dusk built with A-Frame 1.6 (CDN) + aframe-blink-controls.
Open in Meta Quest Browser and press **VR**, or on desktop use WASD + mouse drag.

- Quest: left stick = smooth walk, right stick left/right = 30° snap turn, right trigger = aim arc, release to teleport.
- Desktop: WASD to walk, click-drag to look. "Forest sound" button toggles synthesized ambience (never autoplays).

Assets in `assets/` are 512px composites of the Lil' Foots trait layers plus the gold Lil Foot render (1024px).
